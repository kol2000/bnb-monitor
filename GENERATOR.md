# Генератор кошельков

Откройте вкладку «Генератор кошельков», задайте количество (1–100) и нажмите
«Сгенерировать кошельки». Общий предел проекта — 500 адресов, включая имеющиеся.
Используется лист из настроек Google и установленный сервисный аккаунт с правами
«Редактор». Первая строка должна содержать в B заголовок «адрес», а в C —
«кодовая сид фраза» (также распознаются seed/mnemonic).

Каждый кошелёк получает независимую случайную BIP39-фразу из 12 английских слов.
Адрес выводится по пути `m/44'/60'/0'/0/0`, совместимому с существующим механизмом
переводов проекта. Создание кошелька не требует оплаты газа.

При каждом запуске приложение заново находит первые свободные строки начиная со строки 2.
Свободной считается строка с пустыми A, B и C; оформление не мешает записи.
Пустоты после удаления кошельков используются в порядке сверху вниз.
Строки с именем, адресом, сид-фразой или формулой в A–C пропускаются.
Значения и формулы в остальных столбцах остаются без изменений.
Запись идёт только в B и C выбранных строк:
A остаётся пустым, B содержит адрес, C — сид-фразу. Имена можно заполнить позднее.
Существующие строки не перезаписываются. После подтверждения записи приложение
запрашивает синхронизацию; кошельки появятся в панели при обработке запроса worker.
Остатки записываются обычным механизмом экспорта после проверки балансов.

## Защита от дублей и восстановление

- Повторный запрос с тем же идентификатором возвращает прежний результат.
- Одновременно обрабатывается одна партия; кнопка блокируется на время работы.
- До отправки фразы сохраняются в постоянном Docker-томе в файле
  `/data/generated-<id>.json` с правами 600. В базу и API попадают только адреса.
- После записи приложение сверяет адреса и фразы в Google, затем удаляет
  временный файл. Фразы не отображаются в панели и не выводятся в логи.
- Если ответ потерян, нажмите «Проверить запись». Эта кнопка только читает Google
  и никогда не добавляет строки повторно. Незавершённая партия блокирует новые.
- Если строки действительно не записаны (например, у аккаунта не было прав),
  проверка не будет объявлять успех. Сохраните том: партия остаётся на VM для
  восстановления. Не удаляйте запись из БД и не повторяйте append вслепую.
  Автоматической повторной отправки после неопределённого ответа нет.

Любой, кто получил сид-фразу, может распоряжаться кошельком. Ограничьте доступ
к Google Таблице и резервным копиям Docker-тома. Генератор работает на VM;
сид-фразы передаются только в настроенную Google Таблицу по HTTPS.

## Проверка

`python -m unittest discover -s tests`: генерация и соответствие адресов,
защита от дублей, потерянный ответ, проверка сид-фразы, права файла и API/CSRF.
Google в тестах заменён заглушкой; реальные таблицы не изменяются.
