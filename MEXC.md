# Биржа MEXC

Вкладка сразу после «Кошельки». Кнопка «Проверить баланс и выводы» загружает свободные/заблокированные USDT и BNB, доступные сети и последние выводы BNB за 7 дней (до 1000 записей). Журнал операций приложения сохраняется в SQLite и переживает перезапуск.

## Ключи

Приложение читает `/data/mexc-api.json` в существующем Docker-томе, формат `api_key` и `api_secret`. Файл должен принадлежать пользователю контейнера и иметь права 600. Ключи не передаются в браузер и не сохраняются в Git. Права: чтение аккаунта и ордеров, спотовая торговля, чтение выводов и вывод. Привяжите ключ к реальному исходящему IPv4 VM; после изменения VPN проверьте IP. Часы VM должны быть синхронизированы.

## Покупка и вывод

1. Загрузите баланс и сети. Укажите сумму USDT, выбранную сеть BNB, полный EVM-адрес получателя и memo при необходимости.
2. «Рассчитать покупку»: сумма увеличивается ровно на 0,10 USDT. Например, 50 → MARKET BUY BNBUSDT с `quoteOrderQty=50.10`. Это добавка к покупке, а не фиксированная комиссия MEXC. Биржа применяет собственные комиссии.
3. Подтвердите покупку. Нажмите «Проверить статус»: приложение сверяет ордер и все его исполнения. Неполный набор сделок блокирует вывод. Частично исполненный ещё активный ордер ожидает завершения; терминальный ордер может вывести купленную часть.
4. «Рассчитать вывод BNB» показывает реальную купленную сумму за вычетом комиссии покупки в BNB, актуальную комиссию и сумму заявки. Вывод требует отдельного подтверждения. Расчёты действуют 3 минуты.
5. «Проверить статус» сверяет вывод с историей MEXC. Проверки выполняются по кнопкам; автоматической покупки/отправки при открытии вкладки нет.

Перед выводом дополнительно резервируется комиссия из купленного BNB. Если MEXC удерживает комиссию из суммы заявки, на кошелёк придёт сумма заявки минус комиссия, а резерв останется на бирже. Точность и минимумы берутся из конфигурации сети. Старый BNB на бирже не включается в сумму вывода. Можно выбрать «Оставить BNB на бирже» после подтверждённой покупки.

## Защита от повторов

До каждого POST покупки/вывода состояние фиксируется в базе. На один этап выполняется не более одной попытки POST. Таймаут, HTTP/API-ошибка или перезапуск после фиксации намерения не приводят к автоматической повторной отправке. Используются клиентские ID и сверка ордера/истории. Одновременно разрешена одна незавершённая операция. Межпроцессная блокировка защищает действия двух вкладок браузера.

Если ордер или вывод после ошибки не находится, операция остаётся заблокированной: проверьте её на MEXC и сохраните ID для диагностики. Не удаляйте записи из базы и не создавайте повтор вручную, пока не установлен исход первой попытки. Подтверждённое отклонение POST пока также требует ручной сверки. История MEXC ограничена сроками хранения API; старые неопределённые операции требуют проверки на бирже.

## Обновление

```bash
cd /home/bscbalance/bnb-monitor-git
git pull --ff-only
sudo docker compose build web
sudo docker compose up -d --no-build
```

Обновите браузер Ctrl+F5. Сначала проверьте баланс — это не покупает и не выводит средства. Реальные сделки при разработке не выполнялись; автоматические тесты используют имитацию API.

Документация API: https://mexcdevelop.github.io/apidocs/spot_v3_en/


## Продажа BNB на споте

Рядом с положительным свободным балансом BNB есть кнопка «Продать». Она рассчитывает MARKET SELL BNBUSDT на весь свободный баланс, округлённый вниз по точности ордера. Перед отправкой требуется подтверждение суммы; отображаются ориентировочные USDT до комиссии и остаток BNB. Заблокированные средства не продаются. Баланс ниже минимума либо выше максимума одного ордера отклоняется без отправки. Добавка 0,10 USDT относится только к покупкам.

При незавершённой покупке/выводе продажа заблокирована. Для купленного BNB можно сначала выбрать «Оставить BNB на бирже». После продажи кнопка «Проверить статус» сверяет исполнения и показывает полученные USDT за вычетом комиссии в USDT. Таймаут не вызывает повторную продажу. Весь спотовый баланс, включая BNB вне приложения, входит в расчёт продажи.

BSC выбирается автоматически после загрузки доступных сетей; ручной выбор другой доступной сети сохраняется при обновлении данных в той же странице.
