# Binance, Gate и Bybit

Три независимые вкладки. Binance сохраняет существующие ключи, настройки и журнал.
Gate / Bybit используют отдельные ключи и отдельные очереди операций.
MEXC не возвращается в интерфейс.

## Обновление VM

```bash
cd ~/bnb-monitor-git
sudo python3 manage.py update
```

После обновления нажмите Ctrl+F5 в браузере.

## Ключи Gate и Bybit

Создайте системные HMAC-ключи на основных аккаунтах. Привяжите их к текущему
белому исходящему IPv4 VM. API бирж использует прямое HTTPS-соединение;
Telegram-прокси и переменные прокси окружения к ним не применяются.

- Gate: чтение аккаунта/кошелька и истории, спотовая торговля, вывод.
  Используется обычный спотовый счёт `spot`, без маржи и автозайма.
- Bybit: основной аккаунт, чтение активов/ордеров, спотовая торговля,
  доступ к адресной книге и выводу. Используется единый торговый счёт UNIFIED.
  Средства из Funding переведите в UNIFIED в интерфейсе биржи.
  Вывод выполняется с `accountType=UTA`: биржа переводит средства в Funding сама.

Вводите секреты только в терминале своей VM:

```bash
python3 configure_exchange.py gate
python3 configure_exchange.py gate --check
python3 configure_exchange.py bybit
python3 configure_exchange.py bybit --check
```

Ввод скрыт; файлы `/data/gate-api.json` и `/data/bybit-api.json` имеют права 600.
Замена ключей блокируется, пока у этой биржи есть незавершённая операция.
`--check` только читает баланс, сеть, торговые условия и число записей истории.
Он не покупает, не продаёт и не выводит средства.

Поддерживаются глобальные API `api.gateio.ws` и `api.bybit.com`.
Региональные продукты/домены требуют отдельной интеграции.

## Два разных направления

**Биржа → кошелёк:** покупка BNB за USDT по рынку, затем отдельный расчёт и
подтверждение вывода BSC. Сумма ордера учитывает текущую торговую комиссию,
а цель «на кошельке» также резервирует комиссию вывода. Получение приблизительное:
цена исполнения, удержание комиссий и округление могут отличаться от расчёта.
Покупка автоматически не дополняется вторым ордером. Вывод ограничен BNB этой
покупки и свободным балансом; ранее имевшийся BNB не добавляется.
Продажа округляется вниз и оставляет небольшой запас на возможную комиссию.

**Кошелёк → биржа:** в настройках сохраните отдельно BNB/BSC и USDT/BSC депозиты
Binance, Gate и Bybit. Не копируйте адрес другой монеты или сети автоматически.
При нажатии «Вывести» / «Вывести USDT» выбирается биржа из настроенных направлений.
Перед подтверждением видны биржа, полный адрес, маршрут, сумма и газ.
Изменение выбранного депозитного адреса отменяет неподтверждённый расчёт.
Уже подписанный маршрут сохраняет исходный адрес. Для BNB аккаунт 2 может
отправлять напрямую; для аккаунта 1 сохраняется маршрут через аккаунт 2.

Проверьте доступность депозита и минимальную сумму на самой бирже. Сохранённый
адрес не является доказательством, что биржа сейчас принимает депозиты.

## Ограничение Bybit

API вывода требует заранее добавленный адрес из адресной книги. Приложение до
покупки и повторно перед выводом проверяет BNB/BSC или универсальный BSC-адрес,
его подтверждение и отсутствие ограничения для нового адреса. Регистр букв
должен совпадать с адресной книгой. Для нового адреса из генератора сначала
добавьте его на Bybit; приложение не обходит белый список и период ожидания.
На получение депозитов Bybit с собственных кошельков этот список не распространяется.

Официальные документы:
- https://bybit-exchange.github.io/docs/v5/asset/withdraw
- https://bybit-exchange.github.io/docs/v5/asset/withdraw/withdraw-address
- https://bybit-exchange.github.io/docs/v5/order/create-order
- https://www.gate.com/docs/developers/apiv4/en/spot/
- https://www.gate.com/docs/developers/apiv4/en/withdrawal/

## Статусы и сетевые ошибки

Перед отправкой сохраняются уникальный ID и состояние операции в SQLite.
Файловая блокировка защищает от параллельной отправки из двух вкладок и worker.
На каждой бирже одновременно выполняется одна цепочка покупки/вывода либо продажи;
Binance, Gate и Bybit независимы. Worker сверяет активные операции каждые 30 секунд.
Он отправляет только запросы чтения, не повторяет рыночный ордер или вывод.

Если ответ Bybit на создание вывода потерялся вместе с ID, история API не позволяет
найти его по нашему `requestId`. Нажмите «Указать ID вывода» и вставьте ID из истории
Bybit. Приложение сверяет монету, сеть, адрес, сумму и время. До успешной сверки
повторная отправка запрещена. Отсутствие записи не означает, что деньги не отправлены.
При неоднозначном или неподдерживаемом ответе операция остаётся заблокированной.
Не удаляйте строки журнала вручную ради повторной отправки.

Комиссии с процентной частью, неизвестная точность, отсутствующие параметры API,
требования Travel Rule, не поддержанные данным клиентом, не обходятся: используйте
официальный интерфейс биржи. Разрешения и ограничения конкретного аккаунта проверяются
биржей при запросе. История на вкладке показывает последние записи API, не весь архив.

## Проверка выпуска

Проверено на искусственных ответах API, без реальных ключей и денежных операций.
Перед первой реальной покупкой установите ключи и выполните `--check` на VM.
Документ не утверждает доступность торгов/выводов конкретному аккаунту.


## Вывод USDT на внешний кошелёк

Во вкладках Binance, Gate и Bybit есть отдельный блок «Вывести USDT → внешний
кошелёк». Сейчас поддерживается BSC (BEP20), как и для BNB. Укажите адрес и сумму
заявки либо выберите весь доступный баланс с резервом комиссии. Покупка BNB при
этом не выполняется. Для Bybit выбирается аккаунт списания: Funding (по умолчанию)
или единый торговый UTA; их балансы не складываются и внутренний перевод через
приложение не запускается. Binance и Gate используют спотовый счёт.

Перед подтверждением проверяются актуальные баланс, комиссия, шаг, минимум и
максимум. Комиссия берётся из API в USDT; дополнительно резервируется её сумма.
Для Bybit `feeType=0`: сумма заявки к получению, комиссия сверху. Для Binance/Gate
правила удержания могут уменьшать получение; итог показан по истории биржи.
Режим максимума может оставить резерв, если биржа удерживает комиссию из заявки.
Процентная комиссия, отсутствующие параметры или недоступная сеть останавливают
расчёт. Адрес Bybit USDT/BSC (либо универсальный BSC) проверяется в белом списке
при расчёте и повторно перед отправкой; добавление адреса выполняется на Bybit.

Расчёт действует 180 секунд. После подтверждения окно остаётся открытым и
показывает сохранённый статус, ID и транзакцию. Его можно закрыть и открыть из
списка «Выводы USDT из приложения». Worker сверяет историю каждые 30 секунд;
браузер перечитывает сохранённый статус каждые 3 секунды. Завершение определяется
ответом биржи, не уменьшением баланса. В списке сохраняются последние 50 операций
приложения; чужие/ручные выводы туда не импортируются.

SQLite фиксирует заявку до единственного POST; тайм-аут или перезапуск не запускает
повтор. Для Bybit без ответа с ID требуется «Указать ID вывода» из истории биржи;
совпадение адреса, монеты, сети, суммы и времени обязательно. Отсутствие записи
не снимает блокировку. Одна активная операция на биржу охватывает и новые выводы
USDT, и существующие цепочки BNB. Замена API-ключей при активной операции запрещена.
