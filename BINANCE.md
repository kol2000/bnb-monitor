# Binance и MEXC одновременно

Вкладка «Биржа Binance» находится сразу после MEXC. Ключи, операции, блокировки и фоновые проверки независимы. Эта версия работает со спотом BNBUSDT и выводом BNB через **BSC**; другие сети пока не предлагаются.

## Ключ на существующей VM

1. Binance → Управление API → Создать API → **Сгенерированный системой (HMAC)** → имя `bnb-monitor`.
2. Разрешить чтение, спотовую торговлю и вывод. В интерфейсе Binance торговля может быть объединена с маржинальной торговлей в одном пункте. Приложение использует только спот. Фьючерсы, займы, универсальные переводы не нужны.
3. Разрешить доступ только с доверенного внешнего IP **контейнера VM**. Старый IP после изменения VPN может не подойти. Для проверки:

```bash
cd /home/bscbalance/bnb-monitor-git
sudo docker compose exec -T web python -c "from urllib.request import urlopen; print(urlopen('https://api.ipify.org',timeout=15).read().decode())"
```

4. После обновления приложения установить ключи скрытым вводом:

```bash
python3 configure_binance.py
python3 configure_binance.py --check
```

Ключи передаются в контейнер по stdin, атомарно сохраняются в `/data/binance-api.json` с правами 600. Не записывайте их в репозиторий, чат, скриншоты или команды оболочки. QR-код рядом с ключами тоже скрывайте. `--check` делает только запросы чтения: права, баланс, BSC, история и требования Travel Rule. Реальных ордеров и выводов эта проверка не создаёт.

Если API недоступен именно вашему аккаунту или IP, интерфейс покажет код ошибки. Доступность обычного веб-интерфейса не гарантирует разрешений API. Не меняйте юрисдикцию или сведения аккаунта для обхода ограничений.

## Покупка, продажа, вывод

- «Рассчитать покупку»: ввод 50 USDT создаёт расчёт ордера на 50,10 USDT. Добавка 0,10 — выбранная пользователем надбавка к покупке, а не фиксированная комиссия Binance.
- Покупка требует подтверждения. После исполнения сделки учитываются комиссии в BNB; вывод требует отдельного расчёта и подтверждения.
- Сеть BSC выбирается автоматически, если доступна. Проверяются её минимумы, комиссия, шаг количества и доступность.
- «Продать» продаёт свободный BNB с округлением вниз до допустимого шага. Пыль может остаться; ограничения минимальной стоимости ордера действуют даже при активной кнопке. При балансе меньше 0,0001 кнопка серая.
- Вывод использует спотовый кошелёк (`walletType=0`), только BNB конкретной покупки и резерв на комиссию. При удержании комиссии из суммы заявки на бирже останется резерв; точная сумма и комиссия видны в истории Binance.
- Покупка/продажа и вывод записываются в БД до отправки. При неизвестном результате POST автоматически не повторяется. Фоновая проверка читает ордер, исполнения и историю; отсутствие результата оставляет операцию заблокированной до сверки.
- Если Binance требует Travel Rule или не подтвердил отсутствие требования (`NIL`), покупка с последующим выводом и вывод через приложение блокируются. Для таких аккаунтов пока используйте интерфейс Binance; анкеты автоматически не заполняются.
- История на вкладке показывает до 1000 выводов BNB за 7 дней. MEXC имеет свой отдельный журнал.

## Адреса бирж для переводов с отслеживаемых кошельков

Настройки → Вывод BNB на биржу: выберите MEXC / Binance / другую биржу, сохраните соответствующий депозитный адрес BSC. Известный адрес `0x2ce6195ccdf030fb7fd8d674995728ddcac2148b` подписан MEXC и не может сохраняться как Binance. Поле Binance изначально пустое.

Это **адрес назначения переводов с ваших кошельков**, а не адрес получателя при выводе с самой биржи. Название биржи и адрес сохраняются в каждом новом расчёте и журнале. Переключение настройки отменяет неподтверждённый расчёт, но не меняет уже подписанные переводы. Старые записи с известным адресом MEXC подписаны MEXC; остальные не переименовываются в Binance автоматически.

Проверка адресов/сид-фраз свёрнута в настройках и открывается нажатием на заголовок.
