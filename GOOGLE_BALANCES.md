# Автоматическая запись балансов BNB
После каждого завершённого обхода приложение записывает успешные результаты в подключённую Google Таблицу, только на лист «bnb кошельки».
В первой строке должен быть один заголовок «остаток BNB (BSC)» в столбце C или правее. Адреса берутся из B. Заголовок не создаётся автоматически.
Сопоставление выполняется по адресу без учёта регистра; перестановка строк между обходами поддерживается. Перед записью адреса и заголовки перечитываются. Не сортируйте и не перестраивайте строки непосредственно во время записи: Google Values API не поддерживает условную запись по адресу.
Обновляются только успешно проверенные в текущем обходе кошельки. Ноль записывается числом 0; ошибки RPC и непроверенные адреса оставляют существующие ячейки без изменений.
Значения записываются числами BNB (точность чисел Google Sheets ограничена примерно 15 значащими цифрами; точные wei остаются в приложении). Остальные столбцы и оформление не меняются.
Дайте сервисному аккаунту из установленного JSON-ключа доступ «Редактор» в меню доступа Google Таблицы. Новый ключ не требуется. Приложение запрашивает OAuth scope spreadsheets для записи, импорт продолжает использовать readonly.
В панели Настройки → Google Таблицы отображаются время последней записи, число ячеек и ошибки. Ошибки экспорта не останавливают сканирование и Telegram.
Ручные правки столбца балансов будут заменены следующим успешным результатом. Запись происходит после общего обхода, а не мгновенно после каждой транзакции.
