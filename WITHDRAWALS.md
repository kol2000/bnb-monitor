# Вывод BNB через второй аккаунт

Запуск только вручную: кнопка **«Вывести»** находится под положительным балансом BNB. Само поступление денег не запускает перевод.

1. В настройках сохраните адрес биржи для **BNB в сети BSC**. Начальное значение: `0x2ce6195ccdf030fb7fd8d674995728ddcac2148b`.
2. Нажмите «Вывести». Сервер находит единственную строку выбранного адреса в B и читает сид-фразу из C только этой строки.
3. Используются стандартные пути MetaMask: первый аккаунт `m/44'/60'/0'/0/0`, второй `m/44'/60'/0'/0/1`, без дополнительной BIP39-парольной фразы. Адрес первого обязательно должен совпасть с B. Импортированные отдельными приватными ключами аккаунты и другие пути не поддерживаются.
4. Подтвердите полные адреса и суммы в окне. К первому переводу прибавляется уже существующий BNB второго аккаунта: весь этот баланс, за вычетом второй комиссии, направляется на биржу.
5. Журнал на вкладке «Выводы» показывает оба хеша и состояние. Второй перевод отправляется только после успешной финализации первого. Появление хеша в журнале означает, что транзакция подписана; это ещё не означает её включение в блок или зачисление биржей.

## Ограничения

- Это **только BNB**. USDT и другие токены не переводятся. После обнуления BNB для будущего перевода токенов понадобится пополнение комиссии.
- Только обычные адреса без кода контракта. Приложение проверяет отсутствие кода у отправителей и получателей, отсутствие pending-транзакций и оценку газа 21 000. Смарт-аккаунты и контрактные депозитные адреса не поддерживаются.
- Для каждого перевода резервируется `21 000 × gasPrice`. Цена газа берётся из RPC; предел — 3 Gwei. Для обычного перевода при неизменном балансе отправляется весь остаток за вычетом комиссии. Новое поступление после расчёта или параллельный перевод требуют повторной проверки; абсолютный ноль навсегда не гарантируется.
- Проверьте в интерфейсе своей биржи поддержку BNB/BSC, адрес и минимальный депозит. Приложение не знает правил зачисления вашей биржи.
- Подтверждение расчёта действует 3 минуты. Изменение баланса, nonce, комиссии или настроек до подтверждения отменяет расчёт. Изменение адреса биржи после подтверждения не меняет уже подписанный маршрут.
- Одновременно выполняется один маршрут. Во время вывода не отправляйте транзакции из этих двух аккаунтов в другом приложении.

## Хранение и восстановление

Сид-фразы и приватные ключи не сохраняются в SQLite, не возвращаются браузеру и не записываются в журналы. Они обрабатываются в памяти процесса web. При включении этой функции сервер и его сервисный аккаунт Google получают возможность подписывать переводы: доступ к панели должен оставаться только у владельца.

В постоянной базе сохраняются согласованный маршрут, nonce, суммы, два подписанных сообщения и хеши **до первой отправки**. При потере ответа RPC и перезапуске worker повторяет те же байты; новый перевод с новым nonce автоматически не создаётся. Не удаляйте том Docker и не восстанавливайте старую копию базы поверх выполняющихся переводов. Подписанные сообщения не раскрывают приватные ключи, но дают возможность отправить именно эти переводы; резервные копии также должны оставаться приватными.

Если RPC перестал отвечать, worker проверяет тот же маршрут каждые 15 секунд. При неоднозначном ответе операция остаётся ожидающей. Автоматической замены транзакции с повышенной комиссией нет.

Если баланс/nonce изменился до первой попытки отправки, маршрут приостанавливается. В журнале доступна **«Отменить расчёт»**, после неё можно рассчитать вывод заново. После попытки отправки отмена недоступна: тайм-аут не доказывает, что сеть не приняла перевод.

Если первый перевод подтверждён, а второй приостановлен из-за стороннего изменения баланса/nonce, средства остаются на втором аккаунте. Для этой ситуации автоматического пересчёта и повторного подписания нет: проверьте оба хеша и завершите перевод вручную в MetaMask. Пока неоднозначная операция не разобрана, новый маршрут блокируется; не очищайте её запись вслепую.

## Обновление

Сначала сделайте резервную копию VM/тома. Сборка выполняется только для `web`, образ общий:

```bash
cd /home/bscbalance/bnb-monitor-git
git pull --ff-only
sudo docker compose build web
sudo docker compose stop worker web
sudo docker compose up -d --no-build
```

Обновите браузер через Ctrl+F5. Новый раздел настройки — **«Вывод BNB на биржу»**. Для мониторинга и уведомлений ничего перенастраивать не требуется.

Проверки реализации выполняются только на вымышленных RPC-ответах и общеизвестной тестовой мнемонике. Тесты не отправляют реальные транзакции и не читают пользовательские сид-фразы.
